What this is

Not a guide. A tracker. pbz-tracker reads your Phantom Blade Zero save file (read-only) and warns you before a point of no return when a missable quest or item is still open. If nothing is at risk, it says "No risk of missing anything right now." and you keep playing.

I made it because I wanted to play blind and still get the true ending. Those two things don't go together very well, and this is my compromise: a tool that stays quiet until you're actually about to lose something.

What this is NOT

It is not a guide. A guide has to tell you what's ahead to be useful, and that's exactly the problem for a blind playthrough. This goes the other way: it stays silent until the moment you're about to lock yourself out of something, and then it only tells you where to stop.

Spoiler policy

Warnings describe WHERE to stop, not what's coming: "before this area's final fight", "before the story moves you to the next major area". No boss names, no future regions, no story events. A quest name appears only if that quest is already in your journal. Everything else sits behind a key (G) or the --show flag. Content beyond where you are is never shown.

How to use

1. Download the exe from [RELEASE_LINK] and put it anywhere. It's about 89 MB because it embeds Node; nothing to install.
2. Windows SmartScreen will warn you because the exe is unsigned. Click "More info", then "Run anyway". If you'd rather not trust a random exe, the source is at [GITHUB_REPO] and you can build it yourself.
3. Run it with the game open. It reads your save and shows either warnings or the all-clear line.
4. For live tracking, run it with --watch and leave it open next to the game (second monitor, or alt-tab now and then). Every save (bells/autosave) updates it.
5. Press G (or start with --show) only if you deliberately want the full list. Don't press it if you're playing blind.
6. Languages: the UI is in English and Turkish. If a community text patch (for example the Turkish patch) is installed, quest names are read from it automatically; otherwise English name tables are used. Other languages can be added through a JSON table, contributions welcome.

Is it safe?

Yes, as far as I can make it.
- Read-only. It never writes to your save, backups or game folder.
- No network at all.
- It doesn't touch the running game process.
- The exe contains no key, SteamID or personal data (the build scans itself for this). The decryption key is derived from your own PBZ.exe at runtime.
- It shows the game build it was tested on (26367565) and warns if your game is newer.

Known limits (v0.3.0, please read)

- Two late-game cutoffs aren't detected yet. I'll add them once I reach them myself.
- Some quest-ID mappings are educated guesses, marked with *.
- One accessory can't be detected from the save at all.
- Built fast and new, so expect rough edges. It's not perfect.

Where the rules come from

What's missable and where the cutoffs are comes from public guides: Game8, Maxroll, PowerPyx, allthings.how. Credited in the repo. Rules live in a JSON file; a planned feature will let you drop an updated rules.json next to the exe without waiting for a new release.
