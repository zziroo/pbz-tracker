Description

pbz-tracker reads your Phantom Blade Zero save (read-only) and warns you before a point of no return if a missable quest or item is still open. By default it only shows warnings you can act on. If nothing is at risk you get one line: "No risk of missing anything right now."

I made it because I wanted to play blind and still get the true ending, and a full missables guide would have ruined the blind part. It's not a guide. Think of it as a safety net for a blind run.

Web version (recommended): https://zziroo.github.io/pbz-tracker/
Click the link, choose your game folder, done. Nothing is downloaded and no file is uploaded, it all runs in your browser.

About spoilers: warnings say WHERE to stop, like "before this area's final fight" or "before the story moves you to the next major area". No boss names, no future regions, no story events. A quest name only shows up if that quest is already in your journal. The Journal tab (quest status, step counters, missed items) is blurred and a row only opens when you click it. Nothing past where you are is ever shown.

There are four tabs: Warnings (the default), Journal (blurred), Settings (language, refresh interval, game folder) and About. Leave it open next to the game. It refreshes by itself every time the game saves (resting at a bell, autosave). The UI is in English and Turkish (TR/EN switch). If you have a community text patch installed, the Turkish one for example, quest names are read from it automatically. Otherwise it uses English name tables. Other languages can be added with a JSON table.

It shows the game build it was tested on (26367565) and warns you if yours is newer.

Requirements

- Phantom Blade Zero installed. The decryption key is derived from your own PBZ.exe, nothing is bundled.
- Web version: desktop Chrome or Edge for folder access and live refresh. Firefox and Safari work too if you drag & drop your save (and PBZ.exe once), but there's no auto refresh.
- Exe (alternative): Windows. Node is embedded in it, that's why it's ~89 MB.

Installation

Web: open https://zziroo.github.io/pbz-tracker/ , click "Choose game folder", pick the game folder (or your Steam library folder) and allow read access. After that it's one click. You can also install it as an app if you want it in its own window.

Exe, if you'd rather have a local app:
1. Download pbz-tracker-v0.5.0.exe from https://github.com/zziroo/pbz-tracker/releases/tag/v0.5.0 and put it anywhere. Nothing to install.
2. It's unsigned, so SmartScreen will warn you. "More info", then "Run anyway". The source is at https://github.com/zziroo/pbz-tracker if you'd rather build it yourself.
3. Double-click it. A window opens with the same tabs. It finds the game by itself, or asks you for the game folder.

Safety: it's read-only. It never writes to your save, backups or game folder, and it doesn't touch the running game. Web: no file is uploaded and no request leaves the page (you can check in DevTools, Network tab). The key comes from your own PBZ.exe and stays in that browser. Exe: no internet. The window only talks to the tool itself on 127.0.0.1 (your own PC). There's no key, SteamID or personal data in the exe, the build scans itself to make sure.

Known issues (v0.5.0)

- It's new and I built it fast, so expect rough edges.
- Some later story cutoffs can't be detected from the save yet. Warnings there go by quest state only.
- Some quest-ID mappings are educated guesses. Those are marked with *.
- A few items can't be detected from the save at all.
- The rules come from guides and player reports, and those don't always agree.
- If it flags something wrong, open an issue on GitHub: https://github.com/zziroo/pbz-tracker
