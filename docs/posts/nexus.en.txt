Description

pbz-tracker reads your Phantom Blade Zero save (read-only) and warns you BEFORE a point of no return when a missable quest or item is still open. By default it shows only actionable warnings; if nothing is at risk you get one line: "No risk of missing anything right now."

I made it because I wanted to play blind without losing the true ending, and reading a full missables guide would have ruined the blind part. It is not a guide; think of it as a safety net for a blind playthrough.

Web version (recommended): https://zziroo.github.io/pbz-tracker/
Click the link, choose your game folder, done. Nothing is downloaded and no file is uploaded; everything runs in your browser.

Spoiler-safe by design. Warnings say WHERE to stop ("before this area's final fight", "before the story moves you to the next major area"), never boss names, future regions or story events. Quest names appear only if the quest is already in your journal. The Journal tab (quest status, step counters, missed items) is blurred; a row opens only when you click it. Content beyond where you are is never shown.

Four tabs: Warnings (the default view), Journal (blurred), Settings (language, refresh interval, game folder) and About. Leave it open next to the game: it refreshes on its own every time the game saves (resting at a bell, autosave). Tool UI in English and Turkish (TR/EN switch). If a community text patch (e.g. the Turkish patch) is installed, quest names are read from it automatically; otherwise English name tables are used. Other languages can be added via a JSON table.

Shows the game build it was tested on (26367565) and warns if your game is newer.

Requirements

- Phantom Blade Zero installed (the decryption key is derived from your own PBZ.exe; nothing is bundled)
- Web version: desktop Chrome or Edge for folder access and live refresh. Firefox and Safari work too: drag & drop your save (and PBZ.exe once), but without automatic refresh.
- Exe (alternative): Windows. Node is embedded in the exe, which is why it's ~89 MB.

Installation

Web: open https://zziroo.github.io/pbz-tracker/ , click "Choose game folder", pick the game folder (or your Steam library folder) and allow read access. Next time, one click is enough. You can also install it as an app to keep it in its own window.

Exe, if you prefer a local app:
1. Download pbz-tracker-v0.5.0.exe from https://github.com/zziroo/pbz-tracker/releases/tag/v0.5.0 and put it anywhere. No install.
2. SmartScreen will warn because the exe is unsigned: "More info" -> "Run anyway". Source is public at https://github.com/zziroo/pbz-tracker if you prefer to build it yourself.
3. Double-click it. A window opens with the same tabs; it finds the game on its own, or asks you for the game folder.

Safety: read-only. It never writes to your save, backups or game folder, and doesn't touch the running game. Web: no file is uploaded and no request leaves the page (check it in DevTools -> Network); the key is derived from your own PBZ.exe and kept in that browser only. Exe: no internet; the window talks only to the tool itself on 127.0.0.1 (this computer). The exe contains no key, SteamID or personal data (the build scans itself).

Known issues (v0.5.0)

- New and built fast; it's not perfect. Expect rough edges.
- Some later story cutoffs can't be detected from the save yet; there the warnings rely on quest state only.
- Some quest-ID mappings are educated guesses, marked with *.
- A few items can't be detected from the save at all.
- The rules come from guides and player reports, which don't always agree.
- If it flags something wrong, open an issue on GitHub: https://github.com/zziroo/pbz-tracker
