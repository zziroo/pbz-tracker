[h1]Not a guide. A seatbelt.[/h1]
[b]pbz-tracker[/b] reads your Phantom Blade Zero save (read-only) and warns you [b]before[/b] a point of no return when a missable quest or item is still open. If nothing is at risk, it says [i]"No risk of missing anything right now."[/i] and you keep playing.

I made it because I wanted to play blind and still get the true ending. Those two things don't go together very well; this is my compromise: a tool that stays quiet until you're actually about to lose something.

[b][url=https://zziroo.github.io/pbz-tracker/]Open the web version[/url][/b]: click the link, choose your game folder, done. Nothing is downloaded, no file is uploaded.

[IMAGE docs/screenshots/web-warnings.png  — Warnings tab, web version]

[hr][/hr]

[h2]What it is not[/h2]
It is [b]not a guide[/b]. A guide has to tell you what's ahead to be useful, and that's exactly the problem for a blind playthrough. This goes the other way: it stays silent until the moment you're about to lock yourself out of something, and then it only tells you [i]where[/i] to stop.

[h2]Spoiler policy[/h2]
[list]
[*]Warnings describe [b]where[/b] to stop, not what's coming: [i]"before this area's final fight"[/i], [i]"before the story moves you on to the next major area"[/i].
[*]No boss names, no future regions, no story events.
[*]A quest name appears only if that quest is already in your journal.
[*]Everything else sits in the [b]Journal[/b] tab, blurred. A row opens only when you click it. Don't click if you're playing blind.
[*]Content beyond where you are is never shown.
[/list]

[IMAGE docs/screenshots/web-journal.png  — Journal tab, names blurred until you click a row]

[h2]How to use (web version, recommended)[/h2]
[olist]
[*]Open [url=https://zziroo.github.io/pbz-tracker/]the web version[/url] in [b]Chrome[/b] or [b]Edge[/b].
[*]Click [b]Choose game folder[/b] and pick the game folder (or your Steam library folder). The browser asks for read access; allow it. Next time, one click ([b]Continue with PBZ[/b]) is enough.
[*]Leave it open next to the game (second monitor, or alt-tab now and then; you can also install it as an app to get its own window). Every time the game saves (resting at a bell, autosave), it refreshes on its own.
[*]Tabs: [b]Warnings[/b] (default; only what you're about to lose), [b]Journal[/b] (quest status, step counters, missed items; blurred), [b]Settings[/b] (language, refresh interval, game folder) and [b]About[/b].
[*][b]Firefox or Safari:[/b] drag & drop your save (and PBZ.exe once) onto the page. It works, but without automatic refresh; drop the save again after the game saves.
[/olist]

[IMAGE docs/screenshots/web-setup.png  — first visit: choose the game folder]

[h2]The exe (alternative)[/h2]
[olist]
[*]Download [b]pbz-tracker-v0.5.0.exe[/b] from [url=https://github.com/zziroo/pbz-tracker/releases/tag/v0.5.0]the release page[/url] and put it anywhere. It's about 89 MB because it embeds Node; nothing to install.
[*]Windows SmartScreen will warn you because the exe is unsigned. Click [b]More info[/b], then [b]Run anyway[/b]. If you'd rather not trust a random exe, the source is on [url=https://github.com/zziroo/pbz-tracker]GitHub[/url] and you can build it yourself.
[*]Double-click it. A window opens with the same tabs. It finds your Steam install on its own; if it can't, you choose the game folder in Settings.
[/olist]

[h2]Languages[/h2]
The tool itself speaks English and Turkish (TR/EN switch). If a community text patch (for example the Turkish patch) is installed, quest names are read from it automatically; otherwise English name tables are used. Other languages can be added through a JSON table; contributions welcome.

[hr][/hr]

[h2]Is it safe?[/h2]
Yes, as far as I can make it:
[list]
[*][b]Read-only.[/b] It never writes to your save, backups, game folder or patch.
[*][b]Web version:[/b] everything runs in your browser. No file is uploaded and no request leaves the page (check it in DevTools → Network). The decryption key is derived from [i]your own[/i] PBZ.exe and kept in that browser only.
[*][b]Exe:[/b] no internet. The window talks only to the tool itself on 127.0.0.1 (this computer). The exe contains no key, SteamID or personal data (the build scans itself for this); the key is derived from [i]your own[/i] PBZ.exe at runtime.
[*]It doesn't touch the running game process.
[*]It shows the game build it was tested on ([b]26367565[/b]) and warns if your game is newer.
[/list]

[h2]Known limits (v0.5.0, please read)[/h2]
[list]
[*]Some later story cutoffs can't be detected from the save yet; there the warnings rely on quest state only.
[*]Some quest-ID mappings are educated guesses, marked with [b]*[/b].
[*]A few items can't be detected from the save at all.
[*]The rules come from guides and player reports, which don't always agree.
[*]Built fast and new, so expect rough edges. It's not perfect. If it flags something wrong or misses something, tell me.
[/list]

[h2]Where the rules come from[/h2]
What's missable and where the cutoffs are comes from public guides and players: Game8, PowerPyx, [url=https://www.dtgre.com]DTGRE[/url], the [url=https://steamcommunity.com/app/4115450/guides/]Steam Community guides[/url], the [url=https://steamcommunity.com/app/4115450/discussions/0/572679490124259489/]forum thread on the point of no return[/url] and player reports from the Steam forums. Credited in the repo. Save decompression is a port of ooz by Powzix (Oodle).
The rules live in a JSON file next to the code; when a guide or a player report corrects something, the file gets corrected. The web version is rebuilt and republished automatically on every rule fix; for the exe, drop the repository's latest [b]rules.json[/b] (data/rules.json) next to it, no new release needed.

[h2]Feedback[/h2]
Wrong warning, missed quest, bad mapping: open an issue at [url=https://github.com/zziroo/pbz-tracker]GitHub[/url]. Mapping corrections are especially welcome. Free and open source (GPL-3.0-or-later).
