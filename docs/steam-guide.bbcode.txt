[h1]Not a guide. A seatbelt.[/h1]
[b]pbz-tracker[/b] reads your Phantom Blade Zero save (read-only, it never writes anything) and warns you before a point of no return if a missable quest or item is still open. If nothing is at risk it just says [i]"No risk of missing anything right now."[/i] and you carry on.

I made it because I wanted to play blind without losing quests, memory flowers or items to a cutoff I didn't know was there. Those two don't really go together: a guide ruins the blind part, and skipping the guide means something probably gets locked away for good. So I ended up writing a small tool that stays quiet until I'm actually about to lose something. That's the seatbelt in the title, it doesn't steer, it just catches you.

[b][url=https://zziroo.github.io/pbz-tracker/]Open the web version[/url][/b], pick your game folder, that's it. Nothing is downloaded, no file is uploaded.

[previewimg=48488276;sizeFull,inline;web-warnings.png][/previewimg]

[h1]Grouped by where you are[/h1]
The Warnings tab is split by region. [b]"Now: <region>"[/b] is where you are at the moment, going by the last bell you used, and it holds the stops that apply right there. Regions you've already been through sit below it under their own name, in case something got left behind. Everything else is folded into one block called [b]"Later"[/b], with no region name on it. A region you haven't reached yet is never named anywhere, so the headings themselves don't give away where the story goes next.

[h1]Spoiler policy[/h1]
A guide has to tell you what's ahead to be of any use, and that's the exact thing you don't want on a blind run. This goes the other way: it keeps quiet until you're about to lock yourself out of something, then tells you where to stop, and that's all you get out of it.
[list]
[*]Warnings describe WHERE to stop, not what's coming. Stuff like "before this area's final fight" or "before the story moves you on to the next major area".
[*]You won't see boss names or future regions in there, and no story events either.
[*]A quest name only shows up if that quest is already in your journal.
[*]Quests already in your journal and anything already done show their name and status; step counters, notes and anything you haven't met yet stay blurred. In the Journal tab a row only opens when you click it, so if you're playing blind, don't click it.
[*]Anything past where you currently are is never shown at all.
[/list]

[h1]How to use[/h1]
[olist]
[*]Open [url=https://zziroo.github.io/pbz-tracker/]https://zziroo.github.io/pbz-tracker/[/url] in Chrome or Edge.
[*]Click Choose game folder and pick the game folder (or your whole Steam library folder, that works too). The browser asks for read access, allow it. Next time it's one click, "Continue with PBZ".
[*]Leave it open next to the game. Second monitor, or just alt-tab now and then. You can also install it as an app if you want it in its own window. Every time the game saves (the bell, autosave) it refreshes by itself.
[*]Tabs: Warnings (default, only what you're about to lose, grouped by region), Journal (quest status, step counters, missed items, blurred), Settings (language, refresh interval, game folder), About.
[*]Firefox/Safari: drag and drop your save onto the page (and PBZ.exe, once). Works, but there's no auto refresh, so you have to drop the save again after the game saves.
[/olist]

[h1]Languages[/h1]
English and Turkish (TR/EN switch). If you have a community text patch installed (the Turkish one for example), quest names get read from it automatically, otherwise it falls back to the English name tables. Other languages can be added with a JSON table, contributions welcome.

[h1]Safety, limits, sources, feedback[/h1]
[h1]Is it safe?[/h1]
[list]
[*]Read-only. It never writes to your save, backups, game folder or patch.
[*]Everything runs in your browser. No file is uploaded and no request leaves the page (you can check in DevTools, Network tab). The decryption key is derived from YOUR OWN PBZ.exe and stays in that browser.
[*]It doesn't touch the running game process.
[*]It shows the game build it was tested on (26367565) and warns you if yours is newer.
[/list]

[h1]Known limits[/h1]
[list]
[*]Some of the later story cutoffs can't be detected from the save yet. Warnings there go by quest state only.
[*]Some quest-ID mappings are educated guesses. Those are marked with *.
[*]A few items just can't be detected from the save at all.
[*]The rules come from guides and player reports, and those don't always agree with each other.
[*]This is new and I built it fast, so expect rough edges. If it flags something wrong, tell me.
[/list]

The rules sit in one JSON file. When a guide or a player report corrects something, I correct the file. The web version rebuilds itself on every rule fix.

[h1]Feedback[/h1]
Wrong warning, missed quest, bad mapping: open an issue at [url=https://github.com/zziroo/pbz-tracker]github.com/zziroo/pbz-tracker[/url]. Mapping corrections are especially welcome. Free and open source (GPL-3.0-or-later).

Want to check the rules against your own saves? The terminal version's --archive option (node pbz.js --watch --archive) keeps a copy of every save it reads, named by save date. Details in the README.
