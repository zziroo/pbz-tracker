# pbz-tracker v0.7.0

**Tested with game build 26367565** (Steam). Web version: https://zziroo.github.io/pbz-tracker/

## English

- **New look.** Ink-and-paper theme in the spirit of the game: paper texture, brush-stroke dividers, red seal accents, serif headings. Same layout, tabs and keyboard shortcuts; no external fonts or resources, the page still works offline.
- **Journal rows show what they are.** A small icon marks each row as a quest, an item, an accessory, a memory-flower petal, a chest, a weapon or a tip, so a non-quest entry such as an accessory is no longer mistaken for a quest.
- **Maps tab (3).** The game's own map completion, recomputed from your save with the same rules the game uses: per region the percentage, the counts per category (bells, Sha-Chi amber, blackstone, memory flowers, weapons, Phantom Edges, accessories, medicines, trial points) and the list of what is still missing. Only regions you have reached are listed; missing items are blurred until you click them, and the nearest bell is named only with the "exact names" setting.
- **Names come from the game's own data tables.** Item, weapon, Phantom Edge, accessory, bell and quest names are now derived from the game's DataTables instead of guides and guesswork (`data/game/`, built by `research/gamedata/`). Every code of a finished save matches; 16 guessed entries were corrected. Some quest titles changed to what the game itself uses (for example the lion-dance collectible quest is titled after its location).
- **Three previously undetectable missables are now read from the save** (a new `actorSeen` rule condition reads opened chests): the Boulderguard accessory, the last petal of the first Crimson Forest memory flower, and the amber chests before the Village of Lu lift. A finished save shows no "undetectable" row any more.
- Rules 2026-11-09.5: Thundermoon Lantern is part of the Mirage Estate count (it comes from Zhang in the sanctuary); Seal of Dugu is delayed, not lost, if you choose to mourn; Quick Hand's Request completes on its last branch.
- Developers: `node research/gamedata/build.js --save <decoded save>` prints the game's map completion and the missing entries with coordinates. Extracted game assets never enter the repository.

## Türkçe

- **Yeni görünüm.** Oyunun ruhuna uygun mürekkep-kağıt teması: kağıt dokusu, fırça darbesi ayraçlar, kırmızı mühür vurguları, serif başlıklar. Düzen, sekmeler ve kısayollar aynı; dış font ya da kaynak yok, sayfa çevrimdışı çalışmaya devam ediyor.
- **Günlük satırları ne olduğunu gösteriyor.** Küçük bir simge her satırı görev, eşya, aksesuar, anı yaprağı, sandık, silah ya da ipucu olarak işaretliyor; aksesuar gibi görev olmayan kayıtlar artık görev sanılmıyor.
- **Haritalar sekmesi (3).** Oyunun kendi harita tamamlanma sayımı, kaydından oyunla aynı kurallarla yeniden hesaplanıyor: bölge başına yüzde, kategori sayaçları (çanlar, Sha-Chi kehribarı, karataş, anı çiçekleri, silahlar, Phantom Edge'ler, aksesuarlar, ilaçlar, sınav noktaları) ve hâlâ eksik olanların listesi. Yalnız ulaştığın bölgeler listelenir; eksikler tıklayana kadar bulanık, en yakın çan yalnız "tam adlar" ayarıyla gösterilir.
- **Adlar oyunun kendi veri tablolarından.** Eşya, silah, Phantom Edge, aksesuar, çan ve görev adları artık rehber ve tahmin yerine oyunun DataTable'larından türetiliyor (`data/game/`, `research/gamedata/` ile üretilir). Bitmiş bir kaydın tüm kodları eşleşiyor; 16 tahmin düzeltildi. Bazı görev başlıkları oyunun kullandığı hâle geldi (örneğin aslan dansı toplama görevi bulunduğu yerin adını taşıyor).
- **Daha önce algılanamayan üç kaçırılabilir artık kayıttan okunuyor** (yeni `actorSeen` koşulu açılmış sandıkları okur): Kayakoruyan aksesuarı, Kızıl Orman'daki ilk anı çiçeğinin son yaprağı ve Lu Köyü asansörü öncesi kehribar sandıkları. Bitmiş bir kayıtta "algılanamıyor" satırı kalmıyor.
- Kurallar 2026-11-09.5: Gökgürültüsü Ayı Feneri Serap Malikânesi sayımına dahil (sığınaktaki Zhang verir); Dugu Mührü yas seçiminde kaybolmaz, gecikir; Çabuk El'in İsteği son dalında tamamlanmış sayılır.
- Geliştiriciler: `node research/gamedata/build.js --save <çözülmüş kayıt>` oyunun harita yüzdesini ve eksikleri koordinatla yazar. Çıkarılan oyun varlıkları depoya girmez.
