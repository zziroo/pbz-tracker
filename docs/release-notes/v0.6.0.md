# pbz-tracker v0.6.0

**Tested with game build 26367565** (Steam).

## English

The tracker is now only the web version: https://zziroo.github.io/pbz-tracker/

- **The exe and the local window are gone.** There is no download any more; the web page has the same engine, tabs and spoiler layers, and runs entirely in your browser (nothing is uploaded). If you used the exe, open the page and choose your game folder once.
- **Exact mode** (Settings → "Show place and boss names in warnings", off by default): warnings name the place and the boss, but only in areas you have already reached. Elsewhere the vague text stays.
- **Diagnostics panel** (bottom of Settings): tool, rules and name-table versions, game build, save date, quests your save has that the name table does not know, and undetectable rules. "Copy report" gives a plain-text report for bug reports, without paths, Steam ids or user names.
- **Local quest timeline:** every read records quest state changes in this browser's storage (IndexedDB, at most 2000 records), for checking the rules after a playthrough. Export, copy or delete it in Diagnostics; the switch there stops recording. An export contains your play times.
- Name fix: the side quest `RenOuMuXin` is now shown as "A Puppet's Wooden Heart".
- The terminal version (`node pbz.js`) stays in the repository for developers and rule checks; it no longer opens a window and no longer writes a timeline file.

## Türkçe

Takipçi artık yalnız web sürümü: https://zziroo.github.io/pbz-tracker/

- **Exe ve yerel pencere kaldırıldı.** İndirilecek bir şey yok; web sayfasında motor, sekmeler ve spoiler katmanları aynı, her şey tarayıcında çalışır (hiçbir şey yüklenmez). Exe'yi kullandıysan sayfayı aç ve oyun klasörünü bir kez seç.
- **Tam ad modu** (Ayarlar → "Uyarılarda yer ve boss adlarını göster", varsayılan kapalı): uyarılar yeri ve boss'u adıyla söyler, ama yalnız ulaştığın bölgelerde. Diğer yerlerde belirsiz metin kalır.
- **Tanılama paneli** (Ayarlar'ın altında): araç, kural ve ad tablosu sürümleri, oyun build'i, save tarihi, save'inde olup ad tablosunun tanımadığı görevler ve algılanamayan kurallar. "Raporu kopyala" hata bildirimi için düz metin verir; yol, Steam kimliği ya da kullanıcı adı içermez.
- **Yerel görev zaman çizelgesi:** her okumada görev durum değişiklikleri bu tarayıcının deposuna (IndexedDB, en çok 2000 kayıt) yazılır; oyun bittikten sonra kuralları doğrulamak için. Tanılama'dan indirilebilir, kopyalanabilir ya da silinebilir; oradaki anahtar kaydı durdurur. Dışa aktarılan dosya oynama zamanlarını içerir.
- Ad düzeltmesi: `RenOuMuXin` yan görevi artık adıyla görünüyor: "Bir Kuklanın Tahta Kalbi" (İngilizce: "A Puppet's Wooden Heart").
- Terminal sürümü (`node pbz.js`) geliştiriciler ve kural kontrolü için depoda kalıyor; artık pencere açmıyor ve zaman çizelgesi dosyası yazmıyor.
