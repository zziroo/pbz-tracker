# pbz-tracker v0.3.0

**Tested with game build 26367565** (Steam).

## English

First public release of a local, read-only, spoiler-safe missables tracker for Phantom Blade Zero (PC, Steam).

- Single exe with nothing to install. Run it in a terminal: `pbz-tracker-v0.3.0.exe --watch`.
- Never writes to your save, its backups, the game folder or patches. No network access.
- The save key is derived from your own `PBZ.exe` on each run. The exe contains no key, SteamID or save data.
- Default view shows only actionable warnings, with cutoffs described by position. Details stay hidden behind `--show`, or G in watch mode. Areas you have not reached are never shown.
- Works while the game is running and refreshes when the game saves.
- UI in English and Turkish (`--lang`). Names are read from a detected text patch (for example the Turkish fan translation), with English name tables as the fallback (`--names`).
- Shows the installed game build in the header, with a warning line if that build has not been tested.
- Rules can be updated without a new exe: put the repository's latest `data/rules.json` next to the exe as `rules.json` (or pass `--rules <path>`).

Known limits:

- Some story cutoffs (later regions) cannot be detected from the save yet. Their warnings rely on quest state only.
- A few quest-name mappings are inferred and marked `*` (guess).
- The exe is not code-signed, so SmartScreen may warn on first run.

## Türkçe

Phantom Blade Zero (PC, Steam) için yerel, salt okunur, spoilersız kaçırılabilir takipçisinin ilk herkese açık sürümü.

- Tek exe, kurulum yok. Terminalde çalıştır: `pbz-tracker-v0.3.0.exe --watch`.
- Save'e, yedeklerine, oyun klasörüne ve yamalara yazmaz. Ağa çıkmaz.
- Save anahtarı her çalıştırmada senin `PBZ.exe`'nden türetilir. Exe'de anahtar, SteamID ya da save verisi yoktur.
- Varsayılan görünüm yalnız eyleme dönük uyarıları gösterir ve kesim noktalarını konumla anlatır. Ayrıntılar `--show` ya da watch modunda G ile açılır. Ulaşmadığın bölgeler hiç gösterilmez.
- Oyun açıkken çalışır, oyun kaydettikçe yenilenir.
- Türkçe ve İngilizce arayüz (`--lang`). Adlar bulunan bir metin yamasından okunur (ör. Türkçe yama); yedek olarak İngilizce ad tabloları kullanılır (`--names`).
- Kurulu oyun build'ini başlıkta gösterir; doğrulanmamış bir build'de uyarı satırı çıkar.
- Kurallar exe değişmeden güncellenebilir: depodaki güncel `data/rules.json`'ı exe'nin yanına `rules.json` olarak koy (ya da `--rules <yol>`).

Bilinen sınırlar:

- Bazı hikâye kesim noktaları (ileriki bölgeler) save'den henüz algılanamıyor; uyarıları yalnız görev durumuna dayanıyor.
- Birkaç görev adı eşleşmesi anlamdan çıkarıldı ve `*` (tahmin) ile işaretli.
- Exe kod imzalı değil; SmartScreen ilk çalıştırmada uyarabilir.
